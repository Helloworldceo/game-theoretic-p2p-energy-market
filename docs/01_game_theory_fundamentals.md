# Game Theory Fundamentals

## Basic vocabulary

| Term | Meaning |
|------|--------|
| **Players** | The decision makers (households / prosumers) |
| **Strategies** | The actions each player can choose |
| **Payoff / Utility** | The numerical outcome each player cares about (profit, cost, comfort…) |
| **Information** | What each player knows when choosing a strategy |
| **Rationality** | Assumption that players try to maximize their own payoff |

## Types of games

- **Cooperative vs Non-cooperative**: whether players can make binding agreements.
- **Zero-sum vs Non-zero-sum**: whether one player’s gain is exactly another’s loss.
- **Simultaneous vs Sequential**: whether players move at the same time or one after another.
- **Complete vs Incomplete information**: whether payoffs are known to everyone.

Most energy-market models used in this project are non-cooperative, non-zero-sum, and can be simultaneous (double auction) or sequential (Stackelberg).

## Everyday examples

- Prisoner’s Dilemma → two suspects; each has incentive to confess even though both would be better off staying silent.
- Coordination game → two drivers choosing which side of the road; both want to match.
- Battle of the Sexes → couple choosing entertainment; they want to be together but have different preferences.
